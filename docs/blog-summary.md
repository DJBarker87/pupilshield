PupilSafe AI is a browser-based tool I built that lets UK secondary school teachers use ChatGPT, Claude, and Gemini with real student data — safely. Teachers paste their class data (names, scores, comments), PupilSafe anonymises it with realistic fake names and optional statistical noise, generates a ready-to-use prompt from curated templates, and then de-anonymises the AI's response so real names appear in the final output. The entire round-trip takes under 60 seconds, and no student data ever leaves the browser — there's no backend, no accounts, no data collection.

The core anonymisation engine is a dual-language library (JavaScript for the browser app, Python for server-side integration) built on a seeded PRNG for deterministic, cross-language-identical output. It goes well beyond simple find-and-replace: it scans free-text comments for medical terms, safeguarding keywords, staff names, and regex patterns like postcodes and phone numbers; runs k-anonymity analysis to flag re-identification risks; and in its anonymous mode applies bounded Laplace noise that respects grade boundaries so no student gets accidentally flipped across a pass/fail threshold. The web app is a SvelteKit static site (Svelte 5 with runes, Vite 7, adapter-static) with a seven-step guided pipeline, and the entire stack has zero runtime dependencies beyond PapaParser for CSV handling.
